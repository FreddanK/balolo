# Balolo

Project for experimenting with modern C++ with the goal of creating the 'perfect' setup
and to learn about coding high availability distributed systems in C++.

Potentially I would also like to experiment with introducing Rust as well
and have interoperability between Rust and C++. But that will be in a later stage.

## Getting started

### Install required tools

1. Install `podman`
2. Install [`just`](https://github.com/casey/just#installation) 

### Build and run from terminal

1. From a terminal. Build and start the dev container with `just start-dev-container`
2. From within the dev container. Build and run the program with `just run`
